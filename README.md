# SQC Induction Website

This repository contains a basic website created for **SQC (Statistical Quality Control) induction** purposes.  
The website is designed to introduce users to fundamental SQC concepts in a simple, clear, and beginner-friendly way.

## 📌 Purpose

The goal of this project is to:
- Provide an easy-to-understand introduction to SQC
- Serve as an induction or orientation resource
- Demonstrate basic web development skills using simple technologies

## 🛠️ Technologies Used

- HTML  
- CSS  
- JavaScript (if applicable)

> No external frameworks are required. The project is lightweight and beginner-friendly.
